# 数据库设计

> SQLite 单库；表结构定义在 `backend/migrations/001_init.sql`，运行时由 `database.Migrate` 与 `ensureColumn` 兜底升级。

## users

用户表（MVP 阶段未做注册流程，登录返回固定 user_id=1）。

- `id`
- `username`
- `password_hash`
- `created_at`
- `updated_at`

## models

模型预设。一份 OpenAI 兼容接口配置（provider + 模型名 + base_url + api_key）。

- `id`
- `user_id`
- `provider`：服务商标识，例如 `openai-compatible`
- `model_name`：调用 API 时传给 `model` 字段
- `display_name`：界面用别名（可空）
- `version`：用户自定义版本，便于区分（可空）
- `base_url`
- `api_key`：明文存储，**仅本地使用**
- `masked_key`：脱敏后用于回显
- `created_at` / `updated_at`

## datasets

数据集表。启动时自动从 OpenCompass `configs/datasets/demo/*` 同步内置项。

- `id`
- `code`：唯一标识，对应 OpenCompass demo 配置文件名（去 .py）
- `display_name`、`description`
- `type`：`opencompass_demo` / `opencompass_standard` / `custom`
- `source`：`builtin` / `custom`
- `sample_count`
- `enabled`
- `inference_mode`：`gen` / `ppl` / 空。PPL 仅本地模型可用
- `config_path`、`extra_json`
- `created_at` / `updated_at`

## eval_tasks

评测任务，Go 后端维护全部状态机。

- `id`：短 ID（`ev-` + 10 位 hex，约 13 字符）
- `task_name`：可选，便于检索
- `user_id`
- `model_provider`、`model_name`、`model_base_url`
- `dataset_type`、`dataset_name`
- `status`：枚举见下
- `output_dir`、`error_code`、`error_message`
- `created_at` / `updated_at` / `started_at` / `finished_at`

## eval_results

评测结果表（与 `eval_tasks.id` 1:1）。

- `id`、`eval_task_id` (UNIQUE)
- `metrics_json`：camelCase 数组，每项 `{name, value, displayName, description, extra}`，extra 含 `dataset/mode/model`
- `artifacts_json`：camelCase 数组，每项 `{type, name, path, description}`
- `raw_result_path`、`report_path`、`log_path`
- `metadata_json`：Core 透传（含 `valid_metric_count`、`failure_reason` 等诊断信息）
- `created_at`

## 状态枚举

- `pending`、`validating`、`building`、`running`、`parsing`
- `succeeded`、`failed`、`timeout`、`cancelled`（终态）
