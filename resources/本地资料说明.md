# 本地资料说明

`resources/` 用于记录和放置本地运行所需的大体积资料。大体积源码、数据集、模型文件默认不提交 Git。

## 建议目录

- `resources/opencompass/`：OpenCompass 源码或本地安装说明。
- `resources/opencompass-data/`：OpenCompass demo 数据集和后续标准数据集。
- `resources/models/`：本地模型文件，MVP 暂不要求。
- `resources/datasets/`：自定义数据集，MVP 暂不要求。

## MVP 必备资料

1. Python 运行环境，建议 Python 3.10。
2. OpenCompass 可安装来源，可以是 pip 包或本地源码。
3. OpenCompass demo 数据集。
4. 至少一个可调用的远程 API 模型。
5. 远程 API 的 `base_url`、`model_name`、`api_key`。

## 敏感信息规则

- API Key 不写入本文档。
- API Key 可由用户在前端输入，并由 Go 后端按配置决定是否保存数据库。
- 日志和错误信息不得输出 API Key 明文。
